# 寶石圖示（48 種 × 10 階 = 480 張）

2026-10-07 由 Claude 製作，使用者逐版審閱預覽後核准（兩版：階數外形＋種類顏色 → 加第二色、抗性改純光暈）。
2026-10-08 依使用者要求改光暈規則（見「設計」）：光暈只看階數，抗性寶石不再有專屬光暈，全部 480 張重出。
用在遊戲所有顯示寶石的位置：寶石頁（庫、合成、轉換、拆解、融合、商店）、裝備鑲嵌面板與詳情鑲孔列、神鑄法陣與寶石格、統計卡片。
遊戲專案裡的使用版本在 `images/gems/gem-<key>-<階 01～10>.png`（80×80）；本資料夾的 `master-256/` 是 256×256 母圖。

## 來源

**完全由程式產生**，純 Node（沒有任何外部套件、沒有第三方素材、沒有影像生成）。產生器在 `generator/`，遊戲專案的 `tools/gems/` 是同一份：

| 檔案 | 內容 |
|---|---|
| `gem-core.cjs` | 渲染核心：寶石＝「一組平面取最小值」的凸多面體高度場（每個像素落在哪個平面就是哪個刻面，法線為常數），逐像素打光（漫射＋環境反射的軟光箱＋鏡面）、色階、材質紋理（條紋／網紋／斑點／閃點／遊彩／柔光帶／貓眼縫／虎眼絲光…）、第二色混色、光暈、核心光、抗性光暈、星芒 |
| `gem-defs.cjs` | 48 種外觀表（色階、第二色、材質、家族），key 與 `js/data.js` 的 `GEM_TYPES` 一一對應 |
| `gem-palette.cjs` | 顏色距離（CIELAB 3 群聚類，兩圖以最佳配對的 ΔE 加權平均），撞色檢查與測試共用 |
| `gem-build.cjs` | 出圖指令：`--types --levels --size --out`；`--sheet --cols --label` 出總覽圖；`--check` 檢查與 `GEM_TYPES` 是否對得上 |
| `gem-audit.cjs` | 撞色檢查，兩兩距離低於 12 以非 0 結束 |

重現（在遊戲專案根目錄）：

```
node tools/gems/gem-build.cjs --size 80 --out images/gems       # 遊戲用
node tools/gems/gem-build.cjs --size 256 --out <素材庫>/gems/master-256
node tools/gems/gem-audit.cjs                                    # 改色階後必跑
```

全部是固定種子的確定性運算、沒有 Canvas，所以同一份程式碼在同一版 Node 上逐位元相同。部分雜湊（sha256 開頭）：
遊戲用 80px：ruby-05 `203bb0e4`、wardFire-10 `38975839`、lapis-08 `54fae807`；母圖 256px：ruby-05 `2c64872f`、wardFire-10 `c6e924c5`（2026-10-08 重出後的值）。

## 設計

- **階數看外形**（所有種類共用）：薄片 → 碎塊 → 圓塊 → 六邊 → 菱形（四向星面）→ 長方切角 → 八方 → 星形六邊 → 尖底五邊 → 圓形多邊；階數越高刻面越多、星芒越多、光暈越強。
- **種類看顏色與材質**：48 種各有自己的主色，撞色的加第二色（漸層／中心換色／外緣換色／部分刻面換色）。
- **光暈只看階數**（使用者 2026-10-08 規定）：1～5 階完全沒有光暈，6 階起淡淡出現，隨階數加濃，10 階最濃（強度表 `TIERS.glow`：0.12／0.24／0.38／0.54／0.72）。光暈顏色由 `def.glow` 決定，抗性寶石的光暈色與本體色相不同，所以 6 階起仍認得出。
- **元素類的家族記號**：一般（對屬性敵人傷害）、核（元素傷害提升，內部有發光核心，1 階起就有）、抗（元素抗性，只靠顏色，沒有專屬造型）。三個家族色系相近、主色與核心／光暈色不同。
- 光暈的尾巴在貼邊 22px 內淡出到 0，避免被圖片邊界截斷而在深色格子裡露出方形淡邊。
