# 融火之心漩渦貼圖（vortex-ring / vortex-smoke）

2026-09-22 由 Claude 製作，使用者審閱預覽後核准。用在 `field-dragon-devour`（火龍捲超神【融火之心】的持續場域）。

## 來源

**完全由程式產生**，沒有使用任何第三方素材或影像生成：`generate-vortex.cjs`（Perlin 雜訊＋極座標螺旋，
僅依賴 Node 內建模組）。重現方式：

```
node generate-vortex.cjs . 7
```

產出的兩張 PNG 與這裡的檔案逐位元相同（sha256 開頭 `85ac2376`／`7262eb4d`）。

使用者提供的參考是一張火焰漩渦 GIF（只取得單張靜態畫格）。參考圖只拿來**量測**
半徑方向的亮度與顏色剖面，數值寫在產生器的 `TARGET` 與 `RAMP` 表裡；沒有取樣或描摹參考圖的像素。

## 兩張圖的分工

| 檔案 | 內容 | 用法 |
|---|---|---|
| `vortex-ring.png` | 黃白火環、火絲、鋸齒火舌、往內捲的兩條螺旋火臂 | 兩份同圖錯速旋轉＋交叉淡化 |
| `vortex-smoke.png` | 外圍暗紅煙暈、內部螺旋紅煙、中心紅光 | 慢轉＋反相位副本交叉淡化；另兩份縮小＋加速旋轉做「向內吸」 |

- 1024×1024、8-bit RGB、黑底，**一律 add 混色**。火環的顏色是以「煙渦底光＋火環」取色再減去底光烘焙的，
  兩張疊回去時高光才是參考圖的黃白色。
- 火環在 u = r/512 = 0.632；preset 以 scale 0.3863 顯示，火環落在 authored 半徑 150 的 0.83 倍。
- 遊戲的特效貼圖沒有 mipmap，縮到約 0.4 倍又被地面投影壓扁一半，所以產生器在最後做了 1.2～1.6px 的
  高斯模糊，把會在旋轉時閃爍的最高頻紋理先濾掉。

## 螺旋方向

火臂由環往中心時角度遞減，也就是畫面上**逆時針**往內捲；preset 的 rotationSpeed 因此都是負值。
改成順時針要同時把產生器裡 `ts = tn - k·ln(u)` 的符號反過來，否則煙臂會逆著旋轉方向捲。
