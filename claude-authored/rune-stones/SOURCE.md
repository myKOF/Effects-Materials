# 符文石圖示（stone-r01 ～ stone-r33）

2026-10-07 由 Claude 製作，使用者逐版審閱預覽後核准（共四版：向量幾何 → 高度圖光照的華麗版 → 簡單卵石＋刻痕 → 粗切多邊形立石）。
用在遊戲的「符文」頁（符文庫格子、選中符文大圖、符文真言圖鑑的配方標籤）、裝備頁的符文面板與符文孔列、背包格的符文角標。
遊戲專案裡的使用版本在 `images/runes/stone-rNN.png`（160×160）；本資料夾的 `stone-256/` 是 256×256 母圖。

## 來源

**完全由程式產生**，沒有使用任何第三方素材或影像生成。產生器在 `generator/`（瀏覽器 Canvas 2D，純 JS，沒有外部套件；
遊戲專案的 `tools/rune-stones/` 是同一份）：

| 檔案 | 內容 |
|---|---|
| `rune-stone-core.js` | 渲染核心：512×512 高度圖（Float32Array）、雜訊、模糊、距離場、法線與光照（Blinn-Phong、環境遮蔽、自我陰影）、發光與 bloom |
| `rune-stone-painter.js` | 石頭本體、符文刻痕（V／U 形溝槽，筆畫帶鑿刀的不規則）、合成與共用工具 |
| `rune-stone-bands.js` | 6 個品質色帶各自的外形、材質與點綴 |
| `rune-stone-studio.html`、`rune-stone-server.cjs` | 工作站頁面與本機伺服器（埠 28395）：開頁面按「輸出全部預覽圖」，由伺服器把 PNG 寫到指定資料夾 |

重現方式（在遊戲專案根目錄）：

```
node tools/rune-stones/rune-stone-server.cjs --port 28395 --preview-dir <輸出資料夾>
```

瀏覽器開 `http://localhost:28395/`，按「輸出全部預覽圖」（256px 母圖在 `singles/`）。遊戲用的 160px 版本是在頁面 console 呼叫
`RS.post('stone-rNN', 'sz160', RS.stone(索引, 160))` 逐顆輸出。程序化亂數全部固定種子；但 Canvas 的字型與抗鋸齒因機器而異，
**不保證逐位元相同**，本資料夾的 PNG 才是定稿。部分母圖雜湊（sha256 開頭）：r01 `b1b713a5`、r13 `5fa246b2`、r33 `09644ece`；
遊戲用 160px：r01 `9b8c4870`、r33 `9c0effa6`。

符文字形使用 Unicode 符文區塊的真實字元（資料來自 `js/runeword_data.js` 的 `RUNE_GLYPHS`），字型為系統的
Segoe UI Historic／Noto Sans Runic，只取其輪廓做遮罩並刻進高度圖，沒有把字型檔放進圖裡。

## 參考圖（只參考，沒有描摹或取樣）

使用者提供了幾張參考圖，只拿來決定「方向」，產出是自己畫的：

- 第三方遊戲的符文石截圖（深色石板、中央發光符文）：看光影層次與「刻在凹面裡」的概念。
- 像素風的一排符文石、暗黑 2 重製版風格的灰色河石符文：確認要「簡單的石頭＋刻上符文」、品質靠顏色區分，不要華麗裝飾。
- 一張粗切多邊形立石的形狀圖：藍／橘／金三個色帶的外形語言（不規則七八邊、大平面主面、平面刻面倒角）。

沒有裁切、轉檔、逐像素對應任何外部圖片；外部素材的規範見遊戲專案 `AI_RULES.md` 第二原則。

## 6 個品質色帶（每 6 階一個色帶，對應 `RUNE_TIER_COLORS`）

| 色帶 | 符文階數 | 外形 | 材質與符文光色 |
|---|---|---|---|
| 灰 | 第 1～6 階 | 扁寬橢圓河石 | 花崗岩，細顆粒與微小斑點；暗色刻痕、只有一點冷白微光；無點綴 |
| 綠 | 7～12 | 直立蛋形卵石 | 灰綠石材；翠綠礦脈；底部一小撮苔蘚與兩片小葉 |
| 藍 | 13～18 | 偏高瘦、略向右傾的七邊形立石 | 青灰板岩，平面刻面倒角；青藍礦脈；上緣一點霜晶反光 |
| 紫 | 19～24 | 圓角六邊的寶石切面卵石 | 紫灰石材；紫色礦脈；石面嵌幾粒與表面齊平的紫晶碎粒 |
| 橘 | 25～30 | 偏寬的八邊形不規則石塊 | 暗紅褐玄武岩，帶氣孔；溝槽內是橘紅餘燼漸層；石面零星火星 |
| 金 | 31～33 | 最大的近方正不規則八邊形，倒角最寬 | 近黑的深灰石材帶細金屑；金色礦脈；主面輪廓內縮處一圈極細的金屬刻線 |

同一色帶內，石頭外形一致，只有符文字形不同。刻法：字形遮罩加鑿刀般的不規則邊緣，從「含圓頂的石面」往下挖 V／U 形溝槽，
光源在左上，光源側內壁在陰影裡、背光側內壁被照亮；礦脈只填在溝槽底部，bloom 半徑小，沒有霓虹浮貼的感覺。

## 尺寸與取捨

- 母圖 256×256、遊戲用 160×160，8-bit RGBA、透明背景；構圖置中（外框中心與重心偏移在 ±10px／256 以內）。
- 遊戲裡最大顯示約 64px（符文庫格子與選中大圖），小標籤 24px；34px 與 24px 時 33 顆的字形都認得出，15px 以下主要靠剪影與顏色。
- 藍、橘在 24px 的字形比其他色帶弱（藍面窄、橘的棕底對比低）。
