# 月暈

使用者選定的 UI 懸停音效。44.1 kHz、16-bit、單聲道 PCM WAV，約 106 毫秒。

以三個緩起的衰減振盪器與帶通噪音自製合成，無外部取樣或參考素材。

- 母檔為 `hover-10-moon-glow.wav`。
- 專案副本位於 `audio/ui-preview/hover-10-moon-glow.wav`。
- 執行 `node render.cjs --check` 可比對合成結果與母檔，`node render.cjs --apply` 可重新產生母檔。
- WAV SHA-256 為 `9b2ad705476ad04f4df919008cd34e42a497d2340097e9a15c5da27532718790`。
