# 毒素加持：平面毒水與緩慢內流

2026-10-22 Codex 原創 SVG 64 格／8fps／8秒循環圖集。僅參考使用者所附網路截圖的狹長毒水、破碎邊緣、明暗流紋與細泡沫；未下載、描摹或使用參考圖像素。Mote Studio 可存取，Export 僅 PNG／Sprite sheet／GIF，不支援本次原生 SVG，改採專案向量作者。

依使用者後續明確回饋：水窪中心、寬度與大輪廓固定；邊緣只有0.22材質像素的細微擾動，不能整條扭動。內流材質沿固定水路向外單向平移，每秒8材質像素，8秒移動64像素的無縫週期；底色團塊固定，沒有呼吸或波浪擺動。四臂同樣慢速，無14～17fps不同節奏。

遊戲仍使用表定長度／半寬／伸展速度／壽命與判定，這次只改水窪內部美術動畫；原創重製可由Git歷史回溯先前被使用者否決的直條及扭動版本。重製：node tools/vfx/authoring/author/poison-trail.cjs，再執行 node tools/vfx/export-assets.cjs。
